# 🧪 Manual Testing Project: WhatsApp & Coffee Machine

This repository showcases **end-to-end manual testing projects** for:
- 📱 WhatsApp (Mobile App)
- ☕ Coffee Machine (Embedded System)

It follows the complete **Software Testing Life Cycle (STLC)**, including test planning, case design, execution, defect logging, and reporting.

---

## 🔄 STLC Phases Covered

1. Requirement Analysis  
2. Test Planning  
3. Test Case Design  
4. Test Environment Setup  
5. Test Execution  
6. Defect Reporting  
7. Test Closure

## 📋 Test Planning

Each project includes a detailed test plan that defines:

- Objective & Scope  
- In-Scope / Out-of-Scope Items  
- Test Types (Functional, UI, Negative, etc.)  
- Deliverables  
- Entry & Exit Criteria  
- Risks & Mitigation  
- Team Roles  

---

## 🧪 Test Case Design

Test cases include:

- Test Case ID  
- Description  
- Pre-conditions  
- Steps to Execute  
- Test Data  
- Expected vs. Actual Results  
- Status (Pass/Fail)  
- Remarks

---

## 🐞 Defect Reporting

All failed test cases are logged with:

- Defect ID  
- Title & Description  
- Severity & Priority  
- Steps to Reproduce  
- Status (Open/In Progress/Closed)  
- Tester Comments  

---

## ✅ Test Execution

Each project contains a test execution report summarizing:

- Total Test Cases Executed  
- Pass/Fail Summary  
- Defects Raised  
- Environment Used  
- Cycle-wise Results  

---

## 🔗 RTM (Requirement Traceability Matrix)

Ensures complete test coverage by mapping:

- Requirements ↔ Test Cases ↔ Defects
